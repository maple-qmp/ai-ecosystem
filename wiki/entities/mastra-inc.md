# Mastra 公司

## 描述

总部位于旧金山的 Agent 开发公司，2024 年成立，创始人是 Sam Bhagwat（CEO）、Abhi Aiyer（CTO）和 Shane Thomas（CPO），三人都来自前端框架 Gatsby 团队。公司参加了 Y Combinator 2025 冬季批次，累计融资 3500 万美元，未公开估值。产品分三条线：开源框架 [[entities/mastra|Mastra]]，商业托管平台 [[entities/mastra-platform|Mastra Platform]]，以及用自家框架做的应用 [[entities/mastra-code|Mastra Code]]（终端编程 Agent）和 [[entities/mastra-factory|Mastra Factory]]（软件交付环境）。2026 年下半年加推企业服务：前线部署工程师项目 Mastra Launch、代理商合作计划和上下文服务 Mastra Knowledge。

## 生态位置

- **层级**：[[maps/X-横切主题|X-横切主题]] · 公司（产品集中在 [[maps/L4-开发工具与Agent|L4-开发工具与Agent]]）
- **竞争 / 替代**：[[entities/langchain-inc|LangChain 公司]]、CrewAI 等 Agent 框架公司；[[entities/vercel|Vercel]]（AI SDK 与托管）
