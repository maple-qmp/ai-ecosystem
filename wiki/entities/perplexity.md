# Perplexity

## 描述

AI 搜索产品，自称「答案引擎」：用户提问后它检索网页，生成附引用来源的回答。公司 Perplexity AI 于 2022-08-22 成立，创始人 Aravind Srinivas、Denis Yarats、Johnny Ho、Andy Konwinski，2022-12-07 上线。模型上它两条腿走路：自研的 Sonar 基于 [[entities/llama|Llama]] 3.3，R1 1776 基于 [[entities/deepseek-r1|DeepSeek R1]]；同时调用第三方前沿模型，2026-01 与 Microsoft 签下三年 7.5 亿美元的 Azure 协议，借此使用 OpenAI、Anthropic、xAI 的模型。2025 年起从搜索扩展到浏览器和 Agent：2025-07 推出 Chromium 内核的 Comet 浏览器，2026-02 推出可调度多个模型和子 Agent 的 Perplexity Computer。2026-02 停止广告、转向订阅优先。估值 2026 年初约 212 亿美元。

## 生态位置

- **层级**：[[maps/L5-应用|L5-应用]] · AI 搜索
- **上游依赖**：自研 Sonar（基于 [[entities/llama|Llama]] 3.3）、R1 1776（基于 [[entities/deepseek-r1|DeepSeek R1]]）；第三方 [[entities/gpt|GPT]]、[[entities/claude|Claude]]、[[entities/grok|Grok]]（经 Microsoft Azure / Foundry）
- **竞争 / 替代**：[[entities/chatgpt|ChatGPT]]（联网搜索）、[[entities/gemini-app|Gemini App]] 与 Google 搜索、[[entities/claude-app|Claude 应用]]
