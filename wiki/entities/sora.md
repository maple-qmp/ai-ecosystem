# Sora

## 描述

[[entities/openai|OpenAI]] 的视频生成模型。2024-02-15 以研究预览公布，2024-12-09 向 ChatGPT 付费用户开放。2025-09-30 的 Sora 2 加入同步声音和更真实的物理，并配了一个 iOS 社交应用，10 月以 sora-2 进入 API。2026-03-24 OpenAI 宣布整体退出：Sora 应用和网站 2026-04-26 关闭，Videos API 和全部 Sora 2 模型 2026-09-24 下线，没有宣布替代的视频 API。它是本库第一个被厂商主动关停的前沿模型家族，视频赛道此后由 [[entities/veo|Veo]]、[[entities/kling|可灵]]、[[entities/seedance|Seedance]] 主导。

## 生态位置

- **层级**：[[maps/L2-基础模型|L2-基础模型]] · 模型家族（闭源，视频生成，已停止）
- **上游依赖**：—
- **竞争 / 替代**：[[entities/veo|Veo]]、[[entities/kling|可灵 Kling]]、[[entities/seedance|Seedance / 即梦]]

## 时间线

- 2024-02-15 公布 Sora（研究预览）
- 2024-12-09 向 ChatGPT Plus / Pro 用户开放（美国、加拿大）
- 2025-09-30 Sora 2 与 Sora iOS 应用
- 2025-10-06 DevDay：sora-2 进入 API
- 2026-03-24 宣布停止 Sora 应用与 API
- 2026-04-26 Sora 应用与网站关闭
- 2026-09-24 Videos API 与 Sora 2 模型下线
