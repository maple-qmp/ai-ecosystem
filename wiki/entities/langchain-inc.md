# LangChain 公司

## 描述

总部位于美国的 Agent 工程公司，由 Harrison Chase 与 Ankush Gola 创办。Chase 2022-10 在 Robust Intelligence 任职时发布开源框架 [[entities/langchain|LangChain]]，2023-04 成立公司。产品分两条线：开源框架 [[entities/langchain|LangChain]]、[[entities/langgraph|LangGraph]]、[[entities/deep-agents|Deep Agents]]（MIT 协议），以及收入来源、闭源的商业平台 [[entities/langsmith|LangSmith]]。公司未公开财务数据；TechCrunch 2025-07 估计 ARR 为 1200–1600 万美元，公司称偏低，尚未盈利。公开客户包括 Cisco、Replit、Clay、Cloudflare、Workday、ServiceNow。

## 生态位置

- **层级**：[[maps/X-横切主题|X-横切主题]] · 公司（产品集中在 [[maps/L4-开发工具与Agent|L4-开发工具与Agent]]）
- **竞争 / 替代**：LlamaIndex、CrewAI 等 Agent 框架公司；可观测性方向有 Langfuse、Arize 等

## 产品结构

| 层次 | 产品 | 性质 |
|---|---|---|
| Agent harness | Deep Agents | 开源 |

| 编排运行时 | LangGraph | 开源 |

## 时间线

- 2022-10 Harrison Chase 发布开源项目 LangChain
- 2023-04 成立公司；Benchmark 领投 1000 万美元种子轮，约一周后 Sequoia 领投新一轮
- 2024-02 发布 [[entities/langsmith|LangSmith]]；Sequoia 领投 2500 万美元 A 轮，估值 2 亿美元
- 2025-05-14 LangGraph Platform GA
- 2025-10-20 1.25 亿美元 B 轮，估值 12.5 亿美元，IVP 领投；Sequoia、Benchmark 跟投，新投资方含 CapitalG、Sapphire Ventures、ServiceNow Ventures、Workday Ventures、Cisco Investments、Datadog、Databricks、Frontline
- 2025-10-22 LangChain 1.0、LangGraph 1.0 发布
- 2026-05-14 Interrupt 2026 大会：LangSmith Engine、SmithDB、Managed Deep Agents、Sandboxes GA、LLM Gateway 等；成立研究部门 LangChain Labs（Agent 持续学习，合作方含 Harvey、[[entities/nvidia|NVIDIA]]、Prime Intellect、Fireworks、Baseten）
- 2026-10 Interrupt 纽约 / 伦敦：Managed Deep Agents v0.9、LangSmith Engine v2、Fine-Tuning 等
- 2026-09 二级市场平台 Forge Global 列出约 30 亿美元估值（公司未宣布 C 轮，属估计）
