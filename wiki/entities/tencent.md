# 腾讯

## 描述

微信与 QQ 的母公司，港股上市。大模型业务包括自研[[entities/hunyuan|混元（Tencent HY）]]模型家族、腾讯云的模型 API、AI 助手 App [[entities/yuanbao|腾讯元宝]]，以及编码助手 CodeBuddy、办公 Agent WorkBuddy 和知识库 ima。2025-12 混元的国际品牌改为 Tencent HY；前 OpenAI 研究员姚顺雨出任首席 AI 科学家，2026 年主导重建了预训练与强化学习基础设施。2026 年的 Hy3、Hy4 preview 以 Apache-2.0 开放权重，比早期的自定义许可证宽松得多。腾讯也是国内大模型创业公司的主要财务投资方：[[entities/moonshot-ai|月之暗面]]、[[entities/zhipu-ai|智谱]]、[[entities/minimax|MiniMax]]、[[entities/stepfun|阶跃星辰]]的融资中都有它。

## 时间线

- 2023 参与[[entities/zhipu-ai|智谱]]约 25 亿元融资
- 2023-09 发布混元大模型，先通过腾讯云向企业开放
- 2024-03 参与 [[entities/minimax|MiniMax]] 由阿里领投的 6 亿美元融资
- 2024-05-30 腾讯元宝上线
- 2024-08 参与[[entities/moonshot-ai|月之暗面]] 3 亿美元融资
- 2024-11 开源 Hunyuan-Large；2024-12 开源 HunyuanVideo
- 2025-02-13 元宝接入 DeepSeek-R1；随后微信、ima 等也接入
- 2025-06 开源 Hunyuan-A13B
- 2025-12-05 混元 2.0；12-09 国际品牌改为 Tencent HY；姚顺雨任首席 AI 科学家（入职时间待核实）
- 2026-02 春节红包活动后称元宝 DAU 超 5000 万、MAU 1.14 亿
- 2026-04 下旬 Hy3 preview；07-06 Hy3 正式版，当即接入元宝并下调 API 价格
- 2026-08-27 Hy4 preview（770B，Apache-2.0）
- 2026-11-04 Hy4 正式版
