# Rogo

## 描述

面向投资银行、私募和资管机构的金融 AI 平台，主打替初级分析师完成研究、筛选交易、起草材料等工作，其 Agent 名为 Felix，并接入 Preqin 等金融数据。2024-02 披露种子轮后几乎每半年融资一次：2025-04 B 轮 5000 万美元（Thrive、J.P. Morgan、Tiger Global），2026-01 C 轮 7500 万美元并扩展欧洲，2026-04 D 轮 1.6 亿美元（媒体称 Kleiner Perkins 领投、估值约 20 亿美元），2026-09 又获金融机构战略投资。它也靠收购扩张，一年内买下表格 Agent Subset、Offset、欧洲的 Plux、尽调平台 Rivanna 和会议助手 Arvo。媒体报道其 2026 年 ARR 超过 5000 万美元，超过同类的 Hebbia。
