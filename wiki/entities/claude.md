# Claude

## 描述

[[entities/anthropic|Anthropic]] 的闭源大模型家族，按能力分为 Haiku / Sonnet / Opus 等档位，提供 API、claude.ai 应用及云平台分发。以长上下文、编程与 [[concepts/ai-agent|Agent]] 能力见长。除 Anthropic 自家 API 外，也通过 Amazon Bedrock、Google Cloud、Microsoft Foundry、Claude Platform on AWS 提供；接口格式 [[concepts/anthropic-messages-api|Anthropic Messages API]] 已被许多其他模型服务兼容。行为规范以 [[concepts/claude-constitution|Claude 宪法]] 公开（CC0）。
