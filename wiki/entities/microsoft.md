# Microsoft

## 描述

OpenAI 的主要投资方与云合作伙伴，通过 Azure 提供模型服务；旗下 GitHub 推出 [[entities/github-copilot|GitHub Copilot]]。微软研究院提出了 [[concepts/lora|LoRA]] 等关键微调方法，并开源了分布式训练库 [[entities/deepspeed|DeepSpeed]]（ZeRO），后者 2025 年移交 Linux Foundation、进入 PyTorch Foundation。
