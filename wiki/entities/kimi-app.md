# Kimi App

## 描述

[[entities/moonshot-ai|月之暗面]]的 AI 助手应用，2023-10 以「Kimi 智能助手」上线，靠长上下文出名，单次对话约 20 万汉字；底层是自家的 [[entities/kimi|Kimi]] 模型（2025-07 起的 K 系列开放权重）。2025-09 推出第一个 Agent 模式 OK Computer，能自主规划、执行并调用工具；此后每代模型都先在 App 上线：K2.5（2026-01）、K2.6 Agent（可调用 20 多种工具，Agent Swarm 最多 300 个子 Agent 并行）、K3（2026-07）。2026-06 另推出桌面端本地 Agent 产品 Moonshot Work。公司整体年化收入在 2026-04 底超过 2 亿美元，但其中 B 端 API 占大头，App 单独的用户规模本次没有查到公开数据。
