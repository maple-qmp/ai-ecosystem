# Kimi App

## 描述

[[entities/moonshot-ai|月之暗面]]的 AI 助手应用，2023-10 以「Kimi 智能助手」上线，靠长上下文出名，单次对话约 20 万汉字；底层是自家的 [[entities/kimi|Kimi]] 模型（2025-07 起的 K 系列开放权重）。2024-03 称单次对话可处理 200 万汉字，随后因用户激增宕机两天；月活排名从 2024-08 的第三跌到 2025-06 的第七。2025-09 推出第一个 Agent 模式 OK Computer；此后每代模型都扩展 App 的 Agent 能力：K2.5（2026-01）加入 Agent Swarm，K2.6（2026-04）把它扩展到最多 300 个子 Agent 并行，2026-02 的 Kimi Claw 可在浏览器里一键部署常驻在线的 [[entities/openclaw|OpenClaw]] Agent。2026 年 App 单独的月活没有查到公开数据。

## 生态位置

- **层级**：[[maps/L5-应用|L5-应用]] · 对话助手
- **上游依赖**：[[entities/kimi|Kimi]]
- **竞争 / 替代**：[[entities/doubao-app|豆包 App]]、千问 App、DeepSeek App；海外对标 [[entities/chatgpt|ChatGPT]]、[[entities/claude-app|Claude 应用]]

## 时间线

- 2023-10 Kimi 智能助手上线，单次对话约 20 万汉字
- 2024-03 单次对话提升到 200 万汉字；用户激增导致宕机两天
- 2024-05 推出六档付费方案（4 天 5.2 元至一年 399 元）
- 2024-08 月活排名第三；2025-06 跌至第七
- 2025-09-26 推出 Agent 模式 OK Computer
- 2026-01-27 Kimi K2.5 上线，加入 Agent Swarm
- 2026-02 中旬 Kimi Claw 公测
- 2026-04-20 Kimi K2.6，Agent Swarm 最多 300 个子 Agent 并行
- 2026-06 推出桌面端本地 Agent Moonshot Work（二手报道）
- 2026-07-10 与中国农业银行、美国运通联合发行返 Kimi 会员的信用卡
- 2026-07-16 Kimi K3 发布；2026-10 Kimi K3.1 Pro
