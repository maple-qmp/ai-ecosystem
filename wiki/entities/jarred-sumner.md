# Jarred Sumner

## 描述

[[entities/bun|Bun]] 的作者，[[entities/oven|Oven]] 公司创始人。Bun 起步时，他把 esbuild 的 JavaScript / TypeScript 转译器从 Go 逐行移植到 Zig。二手资料称他此前在 Stripe 工作。2025-12 随 Bun 加入 [[entities/anthropic|Anthropic]]。2026-07 他用 [[entities/claude-code|Claude Code]] 跑约 50 个动态工作流，11 天内把 Bun 从 Zig 重写为 Rust，成了 [[concepts/agent-driven-code-migration|Agent 驱动的代码迁移]]被引用最多的案例。Zig 作者 Andrew Kelley 公开批评过他的工程实践和管理方式。
