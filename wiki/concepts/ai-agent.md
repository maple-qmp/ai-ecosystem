# AI Agent

## 定义

以 LLM 为核心、能自主规划并循环调用工具（搜索、代码执行、API）来完成多步任务的系统。

## 关键特征

- 规划—行动—观察循环
- 依赖工具调用与上下文管理
- 可靠性与评测仍是难点

## 应用

- 编程 Agent
- 研究助理
- 自动化工作流
