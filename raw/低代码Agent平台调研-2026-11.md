# 低代码 Agent 平台与 LLM 网关调研（2026-11）

一句话：补 L4 中“可视化搭建 Agent / 工作流”的一类平台——Dify（LangGenius）、Coze / 扣子（字节跳动，含开源版 Coze Studio 与 Coze Loop）、n8n——以及多模型统一调用层 LiteLLM（BerriAI）。三家低代码平台出身不同：Dify 从“LLM 应用开发平台”起步，Coze 从字节的 Bot 搭建平台起步，n8n 从通用工作流自动化（Zapier 的开源替代）起步，到 2026 年都收敛到“画布 + Agent 节点 + MCP + 人工审批节点”。三者的开源协议都带限制或分层：Dify 是附加条件的 Apache 2.0，n8n 是 fair-code 的 Sustainable Use License，Coze 只开源了核心引擎（Apache-2.0），部分功能仅商业版提供。LiteLLM 则是本库正文中多次出现、但一直没有页面的基础件：DSPy、OpenAI Agents SDK 等框架用它接入非 OpenAI 模型；2026-03 它在 PyPI 上被投毒，导致 Mercor 数据泄露。检索日期 2026-11-07。

## 一、Dify（LangGenius）

- 开源 LLM 应用开发平台：可视化编排 AI 工作流、RAG 管道、Agent、模型管理与可观测性；可云端、VPC 或自托管（一手）。
- 协议：Dify Open Source License，“基于 Apache 2.0 并附加条件”（一手）。GitHub 约 16.1 万星（2026-11-07）；2025-06 博客庆祝 10 万星（一手）。
- 版本（一手博客）：2025-01-09 插件系统；2025-02-17 v1.0.0（插件生态）；2025-07-10 v1.6.0 内置双向 MCP（既可调用 MCP 服务器，也可把 Dify 应用发布为 MCP 服务器）；2025-09 Knowledge Pipeline；2026-02-05 v1.12.0 摘要索引；2026-03-03 v1.13.0 人工输入节点（Human Input）；2026-03-10 创作者中心与模板市场；2026-05-13 v1.14.1 工作流成为团队资产；2026-07-09 官方 CLI difyctl。未见 2.0。
- 融资：2026-03-09 宣布 3000 万美元 Pre-A 轮，HSG（红杉中国）领投，GL Ventures（高瓴）、Alt-Alpha、5Y Capital（五源）、Mizuho Leaguer、NYX 跟投；新闻稿称 Dify 运行在全球 140 多万台机器上，2000 多个团队和 280 家企业使用商业版（一手）；投后估值约 1.8 亿美元（二手）。总部 Menlo Park（一手新闻稿）。

## 二、Coze / 扣子（字节跳动）

- 字节跳动的 AI Agent 开发平台，国内版“扣子”（coze.cn），海外版 Coze（coze.com）。
- 2025-02 字节开源 Go 语言 LLM 应用框架 Eino（二手）。
- 2025-07-29 开源 Coze Studio（可视化 Agent 开发，Go 后端 + React/TypeScript 前端，Docker Compose 部署）与 Coze Loop（Agent 调试、评测、观测），Apache-2.0；48 小时内两仓库合计约 9000 星（二手）。Coze Studio README 称其来自“扣子开发平台”，核心引擎完全开放，部分功能（如音色定制）仅商业版提供（一手）。GitHub 约 2.18 万星（2026-11-07）。
- 2026-01-19 扣子 2.0：Agent Skills、Agent Plan（长期目标拆解与持续执行）、Agent Office（Word / PPT / Excel）、Agent Coding（原开发平台升级为“扣子编程”）（二手）。
- 2026-05-27 / 06-01 扣子 3.0：多人多 Agent 协作，行业技能包，可一键接入 Claude Code、Codex CLI 等外部 Agent（二手；发布日期两说）。

## 三、n8n（n8n GmbH）

- 柏林公司，Jan Oberhauser 2019 年创立（一手 Series C 博客）；npm 包 n8n 2019-04-24 首次发布（一手）。
- 定位：fair-code 工作流自动化平台，原生 AI 能力；可视化画布 + 自定义代码（JavaScript / Python / npm），自托管或云端；README 称 1500+ 集成，仓库简介称 400+（一手，口径不一）。
- 协议：Sustainable Use License（fair-code），另有 n8n Enterprise License（一手）。该协议允许内部使用和自托管，但限制把 n8n 作为商业托管服务转售（训练知识，待核实）。GitHub 约 21 万星（2026-11-07）。
- 2025-10-09 C 轮 1.8 亿美元，估值 25 亿美元，Accel 领投，累计融资 2.4 亿美元；当年用户增长 6 倍、收入增长 10 倍（一手）；NVIDIA NVentures 参投，Accel 称 n8n 上超过 80% 的工作流嵌入了 AI Agent（二手）。
- 2025-12-08 2.0.0 beta，2025-12-15 2.0 稳定版：默认更安全、可靠性与性能，工作流“保存”与“发布”分离（一手 / 二手）。
- 2026-11-04 npm 最新版 2.46.6（一手）。
- 2026-05 有报道称战略投资后估值 52 亿美元（二手，单一来源，待核实）。

## 四、LiteLLM（BerriAI）

- 开源 AI 网关：Python SDK 用 OpenAI 格式统一调用 100 多家 LLM 提供商；Proxy Server（LLM Gateway）供平台团队自托管，提供虚拟密钥、按密钥 / 团队 / 用户的成本追踪与预算、限流、负载均衡与自动回退（一手）。文档页脚标 MIT 协议（一手）。GitHub 约 6.29 万星（2026-11-07）。
- PyPI：0.1.0 于 2023-07-27 上传；2026-11-06 最新版 1.108.2（一手）。
- 2026-03-24 供应链事件：攻击者（TeamPCP）取得维护者 PyPI 账号，发布恶意版本 1.82.7（`import litellm.proxy` 时触发）与 1.82.8（加入 `litellm_init.pth`，任何 Python 启动时触发），窃取凭据；恶意版本从未经官方 GitHub CI/CD 发布（一手 issue）。根源被认为是 CI 中已被入侵的 Trivy 扫描器泄露了发布令牌（二手；issue 中由社区提出）。DSPy、CrewAI、browser-use 等下游受影响（二手）。Mercor 2026-03-31 确认其数据泄露源于此事件（本库 Mercor 页）。
- 2026-04 DSPy 3.2.0 开始与 LiteLLM 解耦（本库 DSPy 页）。
- 2026 年下半年仓库简介改为“Rust core with Python SDK”；另有独立的 LiteLLM-Rust 极简网关（面向编码 Agent）（一手简介 / 讨论帖；性能数字仅见二手）。
- 下游：OpenAI Agents SDK 以 best-effort beta 方式支持 LiteLLM（本库 OpenAI Agents SDK 页）。
