## 1. OpenAI GPT

### 命名变化

- GPT-5（2025-08）起把快速模型、推理模型和路由器合成一个系统，o 系列推理模型并入主线。
- GPT-5.6（2026-07）开始按档位起名：Sol（主力）、Terra（快速、视觉与 computer use）、Luna（低价大批量）；`gpt-5.6` 别名指向 Sol。

## 2. Anthropic Claude

### 档位

- Claude 3 起分 Haiku / Sonnet / Opus 三档；2026 年加了更高一档 Mythos，只开放给经过验证的组织（Project Glasswing、Cyber Verification Program）。Fable 是 Mythos 档位面向公众的版本，带额外安全限制：被判定为网络安全、生物等高风险的请求会被拒绝或降级到其他模型（Wikipedia 称 Fable 5 会降级到 Opus 4.8）。
- 当前阵容（官方总览）：Fable 5.1（$10 / $50）、Opus 5.5（$4 / $20，官方推荐的默认起点）、Sonnet 5.5（$2 / $10）、Haiku 5.5（从 $0.10 / $0.50 起）。四者都是 1M 上下文、128K 输出、自适应思考（adaptive thinking），可靠知识截止 2026-06。
- 4.6 代起模型 ID 不再带日期，每个 ID 都是固定快照。Opus 4.7 引入新分词器。API 版本 `2026-10-21` 删除了 `temperature`、`top_p`、`top_k` 参数。
- 退役承诺：官方承诺长期保存已退役模型的权重；每个当前模型都标注“最早不早于”某日退役（约为发布后一年）。

## 3. Google Gemini

### 档位

- Pro（旗舰）、Flash（性价比）、Flash-Lite（最便宜）、Deep Think（深度推理模式）；图像模型品牌叫 Nano Banana，另有 Live（实时语音）、TTS、Omni（视频生成）、Embedding、Robotics ER 等分支。开放权重的小模型是 Gemma（不在 Gemini API 模型页上）。
- 1.0 代用 multi-query attention；1.5 起是 MoE，上下文 1M（1.5 Pro 曾到 2M）。2.0 之后没有发表技术白皮书（Wikipedia）。训练与推理都在 Google TPU 上。
- **Gemini 4 Argon**（`gemini-4-argon`）：官方描述为旗舰推理模型，1M 上下文、长输出可达 1M token。二手报道称 2026-09-30 发布，先通过 Fairwind Program 给受信网络防御方，10-13 正式开放；标准价 $4 / $20，推广价 $2 / $10 到 11-30。
- 当前 Flash 主力是 Gemini 3.8 Flash（2026-09-02 GA）。Gemini 2.5 Pro / Flash 已弃用，2026-12-01 起请求会转发到 3.8 Flash 和 3.5 Flash-Lite。
