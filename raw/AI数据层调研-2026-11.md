# AI 数据层调研（2026-11）

一句话：梳理 L1 数据层，分四块。一是向量数据库 Milvus（Zilliz）、Qdrant、pgvector、Pinecone、Weaviate、Chroma；二是开放预训练语料 Common Crawl、FineWeb（Hugging Face）、The Pile（EleutherAI）、Dolma（Ai2）；三是合成数据；四是数据标注与人类专家数据公司 Scale AI、Surge AI、Mercor。2026 年的主线：向量库从“独立数据库”往“检索基础设施”收拢（Milvus 3.0 湖原生、Qdrant 5000 万美元 B 轮、Pinecone 换 CEO 并传出售），数据标注从众包转向高价专家数据（Meta 入股 Scale AI 49%，Surge、Mercor 估值超过 Scale）。检索日期 2026-11-05。

## 一、向量数据库

### Milvus（Zilliz）

- README：高性能向量数据库，用 Go 与 C++ 编写，CPU / GPU 硬件加速；完全分布式、K8s 原生，计算与存储分离，可水平扩展到数十亿向量、数万查询；另有 Standalone 单机模式与 `pip install` 即用的 Milvus Lite。
- 索引：HNSW、IVF、FLAT、SCANN、DiskANN 及量化变体、mmap；GPU 索引支持 NVIDIA CAGRA（cuVS）。
- 稀疏向量与混合检索：原生 BM25 全文检索，支持 SPLADE、BGE-M3 等学习型稀疏嵌入，稠密与稀疏向量可存入同一 collection 并重排。
- 多租户（database / collection / partition / partition key 级隔离）、冷热分层存储、RBAC、TLS。
- 治理：LF AI & Data Foundation 项目，Apache 2.0，Zilliz 是主要贡献者；托管版为 Zilliz Cloud（Serverless / Dedicated / BYOC）。
- Milvus 3.0（二手报道，Business Wire 2026-07-31；Zilliz 新闻页与 Wikipedia 给出的日期分别为 2026-07-16、2026-07-29，说法不一）：“湖原生”架构，生产索引与检索可直接运行在对象存储的数据之上；新增去重、聚类等向量原生批处理算子；稀疏索引体积约缩小到 1/3；新存储引擎 Loon；仍是 LF AI & Data 毕业项目、Apache 2.0。pymilvus 3.0.2 于 2026-09-18 上传。
- Zilliz 总部（二手报道，Business Wire 新闻稿电头）：美国加州 Redwood City。
- Zilliz 融资（二手报道）：2022-08 B 轮 6000 万美元，累计约 1.13 亿美元；未找到 2026 年新融资。

### Qdrant

- README：“读作 quadrant”，向量相似度搜索引擎与向量数据库，用 Rust 编写；存储和管理带 JSON 负载（payload）的“点”；托管版 Qdrant Cloud 有免费额度。
- 功能：稠密、稀疏与多向量检索（含 ColBERT 等 late interaction）；丰富的负载过滤（关键词、全文、数值范围、地理位置，`should` / `must` / `must_not` 组合）；混合检索；内置量化，最多降低 97% 内存；分布式部署；REST 与 gRPC 接口；官方客户端 Go、Rust、JS/TS、Python、.NET、Java。
- Qdrant Edge：嵌入应用进程内运行的轻量版本，可与服务端同步，面向边缘设备与离线场景。
- README 提供一套 agent skills（`qdrant/skills`），让编程助手就量化、分片、租户隔离、混合检索等做决策。
- 融资（二手报道）：2026-03-12 宣布 5000 万美元 B 轮，AVP 领投，Bosch Ventures、Unusual Ventures、Spark Capital、42CAP 参投，累计约 8750 万美元；公司总部柏林。
- qdrant-client 1.20.0 于 2026-10-22 上传。

### pgvector

- README：“Open-source vector similarity search for Postgres”，作为 PostgreSQL 扩展（Postgres 13+）运行，向量与其余业务数据存在一起，继承 ACID、时间点恢复、JOIN 等能力。
- 支持精确与近似最近邻；单精度、半精度（`halfvec`）、二值（`bit`）与稀疏（`sparsevec`）向量；L2、内积、余弦、L1、Hamming、Jaccard 距离。
- 索引：HNSW 与 IVFFlat。HNSW 索引维度上限：`vector` 2,000 维、`halfvec` 4,000 维、`bit` 64,000 维、`sparsevec` 1,000 个非零元素。
- 版本：0.1.0（2021-04-20）→ 0.5.0 加入 HNSW（2023-08-28）→ 0.8.0（2024-10-30）→ 0.8.7（2026-10-01）。
- 分发：Docker、Homebrew、PGXN、APT、Yum、conda-forge 等，Postgres.app 与多家托管 Postgres 服务预装。

### Pinecone

- 闭源、全托管的向量数据库服务（无 GitHub 主仓库），PyPI 上 `pinecone` 包最早版本为 4.0.0（2024-05-03），10.3.0 于 2026-11-03 上传。
- 融资（二手报道）：2023-04-27 B 轮 1 亿美元、估值 7.5 亿美元（TechCrunch）；2021 年以来三轮累计约 1.38 亿美元。
- 管理层（二手报道）：2025-09 创始人 Edo Liberty 卸任 CEO 转任首席科学家，前 Google 高管 Ash Ashutosh 接任。同期 The Information、Calcalist 报道 Pinecone 在探索出售，潜在买家包括 Oracle、IBM、MongoDB、Snowflake，背景之一是失去 Notion 这一大客户；未见成交报道。
- 2026 年产品（二手报道，PR Newswire 新闻稿）：Dedicated Read Nodes（专用读节点，2026-04 GA）；AWS 法兰克福区域与面向自主 Agent 的知识引擎 Pinecone Nexus；2026-05 首个亚洲 serverless 区域（新加坡）。新闻稿自称服务 9,000 多家客户、80 万开发者。

### Weaviate

- README：云原生向量数据库，同时存储对象与向量；在一个查询接口里组合向量相似度检索、关键词过滤、RAG 与重排。
- 两种入库方式：导入时用集成的模型提供方（OpenAI、Cohere、Hugging Face 等）自动向量化，或直接导入预先计算的嵌入。内置多租户、复制、RBAC。
- 用 Go 编写；部署方式有 Docker、Kubernetes、Weaviate Cloud 及 AWS / GCP 市场；README 示例镜像版本 1.36.0。weaviate-client 4.24.1（BSD 3-clause）于 2026-10-26 上传。
- 融资（二手报道）：2023-04 B 轮 5000 万美元，Index Ventures 领投、Battery Ventures 参投，公司总部阿姆斯特丹。另有单一来源称 2025-10 有 C 轮，未能证实。

### Chroma

- README：“the open-source data infrastructure for AI”，Apache 2.0；`pip install chromadb` / `npm install chromadb` 即可在进程内使用，也可 `chroma run` 以客户端—服务端模式运行。
- 核心 API 只有 4 个函数：建 collection、`add`（自动分词、嵌入、建索引，也可自带嵌入）、`query`（支持元数据与文档内容过滤）、`get`。
- Chroma Cloud：托管服务，提供 serverless 向量、混合与全文检索，注册送 5 美元额度。
- 每周一发布 PyPI 与 npm 新版本；PyPI 上 chromadb 最新为 1.5.9（2026-05-05）。
- 融资（二手报道）：2023-04-06 种子轮 1800 万美元，Quiet Capital 领投；CEO Jeff Huber，2022 年成立于旧金山。

## 二、预训练语料

### Common Crawl

- （二手报道，Wikipedia 与 Common Crawl 博客）501(c)(3) 非营利组织，2007 年由 Gil Elbaz 创立并任董事长，2008 年起抓取网页并公开数据；累计超过 10 PB，约每月发布一次抓取，每次通常超过 20 亿个网页。资金主要来自 Elbaz 家族基金会，2023 年起开始接受 AI 行业捐赠。
- 下游：Google 的 C4（训练 T5）取自一次 Common Crawl 快照；BLOOM 的 OSCAR、The Pile 的 Pile-CC、FineWeb 都以它为原料。

### FineWeb（Hugging Face）

- （二手报道，NeurIPS 2024 论文与 FineWeb 博客）FineWeb 是 15 万亿 token 的英文网页预训练数据集，取自 96 个 Common Crawl 快照，磁盘约 44 TB；论文称用它训练的 LLM 优于其他开放预训练数据集。
- FineWeb-Edu：用自训练分类器筛出教育类内容的子集，1.3 万亿 token（高教育价值阈值），另有 5.4 万亿 token 的较低阈值版本。两者都以 ODC-By 1.0 许可发布，同时受 Common Crawl 使用条款约束。
- 一手（FineWeb 2 README）：FineWeb 2 是第二版，覆盖 1000 多种语言；起点是原 FineWeb 处理时得到的非英文数据；流程为 GlotLID 语言识别、按语言全局去重（不同于 FineWeb 按快照去重）、按语言单独调参过滤、PII 匿名化；保留去重簇大小 `minhash_cluster_size`，可按簇大小“回填”（rehydrate）上采样。论文 arXiv 2506.20920。
- 一手（datatrove README）：Hugging Face 的数据处理库 datatrove 附带 `fineweb.py` 完整复现 FineWeb，以及读取 Common Crawl WARC、抽取文本、过滤的完整流水线。

### The Pile（EleutherAI）

- 一手（复现代码 README）：大型多样化开源语言建模数据集，由 22 个较小数据集组合而成；有效规模合计 1254.20 GiB（按权重和 epoch 计），最大成分为 Pile-CC（227.12 GiB，权重 18.11%）、PubMed Central、Books3、OpenWebText2、ArXiv、GitHub 等。
- （二手报道）2020-12-31 公开发布，数据表称原始规模 825 GiB。Books3 成分来自盗版站 Bibliotik；2023 年丹麦反盗版组织 Rights Alliance 发出 DMCA 通知后，托管方 The Eye 下架 Books3（TorrentFreak 2023-08-16 报道），社区随后发布去除受版权内容的版本。

### Dolma（Ai2）

- 一手（README）：Dolma 既是数据集也是工具包。数据集为 3 万亿 token，混合网页、学术论文、代码、图书与百科，是 Ai2 OLMo 模型的训练语料，以 ODC-BY 许可在 Hugging Face 发布；工具包支持并行处理数十亿文档、内置 Gopher / C4 / OpenWebText 风格的标注器、用 Rust Bloom 过滤器快速去重。论文 arXiv 2402.00159（2024）。
- （二手报道）Olmo 3 使用 Dolma 3：预训练混合约 6 万亿 token（取自约 9 万亿 token 的清洗池，来源为网页、经 olmOCR 处理的科学 PDF、代码与数学），中训练 Dolmino 约 1000 亿 token，长上下文 Longmino 约 500 亿 token（最长 65K）。各二手来源数字略有出入。

## 三、合成数据

- 一手（Cosmopedia README）：Hugging Face 的 Cosmopedia 是由 Mixtral-8x7B-Instruct 生成的合成教科书、博客、故事与 WikiHow 文章，3000 多万个文件、250 亿 token，README 称是当时最大的开放合成数据集；生成耗时超过 1 万 H100 GPU 小时，用 datatrove 做 MinHash 去重，并针对评测基准做 n-gram 去污染。
- （二手报道，Nemotron-4 340B 技术报告，2024-06）NVIDIA Nemotron-4-340B-Instruct 对齐阶段使用的数据中超过 98% 为合成生成，人工标注只有约 2 万条（用于监督微调和奖励模型训练）；报告认为合成数据对对齐至关重要，因为人工标注成本高；同时开源了合成数据生成流水线，奖励模型用于质量过滤与偏好排序。
- （二手报道，Shumailov 等，Nature 631，2024-07）不加区分地用模型生成内容训练后代模型会导致“模型崩溃”：原始数据分布的尾部逐渐消失，在 LLM、VAE、高斯混合模型中都观察到。
- 归纳（据上述两份资料）：合成数据通常要与真实数据混用，并配合去重、去污染与过滤（奖励模型、分类器）。

## 六、RAG 补充（核实用）

- （二手报道，NeurIPS 2020 论文页与 Meta AI 论文页）Lewis、Perez、Kiela 等提出 RAG：参数化记忆为预训练 seq2seq 模型，非参数化记忆为 Wikipedia 的稠密向量索引，用预训练神经检索器访问；在三项开放域问答任务上达到 SOTA，生成的语言比纯参数化基线更具体、多样、符合事实。
