## 官方原文摘录

- "GLM-4.5 has **355** billion total parameters with **32** billion active parameters, while GLM-4.5-Air adopts a more compact design with **106** billion total parameters and **12** billion active parameters."
- "They are released under the MIT open-source license and can be used commercially and for secondary development."

GLM-4.7 模型卡："GLM-4.7 further enhances **Interleaved Thinking** (a feature introduced since GLM-4.5) and introduces **Preserved Thinking** and **Turn-level Thinking**."

GLM-5 模型卡："Compared to GLM-4.5, GLM-5 scales from 355B parameters (32B active) to 744B parameters"（同卡介绍其异步强化学习基础设施 slime）

- "for the first time, delivers that capability on a **solid 1M-token context**."

- "**Pure Open**: An MIT open-source license — no regional limits, technical access without borders"

GLM-5.3 模型卡："GLM-5.3 uses the same base model as GLM-5.2 — every gain comes from post-training."

## 整理

### 1. 公司概况

- 2019 年在北京成立，源自清华大学知识工程实验室（KEG），核心人物唐杰；首席科学家、CEO 等信息以招股书为准（本次未读招股书）。
- 2022-05 在 ACL 发表 GLM 论文（自回归空白填充预训练）。早期开源 ChatGLM-6B 系列，是国内最早被广泛本地部署的开源对话模型之一。
- 国际品牌 2025-07 起改为 Z.ai；英文公司名为 Knowledge Atlas Technology（2026-07-14 港交所公告更改英文名称与股份简称）。
- 2025-01 被美国商务部列入实体清单。
- 2026-01-08 在港交所上市（代码 2513），是中国首家上市的大模型公司；2026-08 市值约 620 亿美元（Wikipedia）。
- 硬件适配：GLM-4.5 可在 8 张 H20 上运行；2025-08 宣布适配华为昇腾；GLM-4.6 首次在寒武纪芯片上做 FP8 / Int4 量化部署，并在摩尔线程 GPU 上原生 FP8 推理。

### 3. 许可证演变

- 2025-04（GLM-4-0414）起，旗舰与大部分模型改用标准 MIT；GLM-4.5 至 GLM-5.2 均为 MIT。
- **GLM-5.3** 改用自定义 GLM-5.3 License：只有在“模型即服务”业务方及关联方连续 12 个月总收入超过 **100 亿美元**时，商用前需通过 Z.ai 安全审查。门槛只覆盖超大云厂商，审查的标准、费用和时限在许可证中没有写明。GLM-5.3-Flash 仍是 MIT。
- 对比：月之暗面 Kimi K3 的同类 MaaS 门槛是年收入 2000 万美元、需另签协议；MiniMax M3 是社区许可证（非商用免费，商用需通知、年收入超 2000 万美元需书面授权）。

### 4. 开发者生态

- **Anthropic 兼容端点**：`api.z.ai/api/anthropic`（国内 `open.bigmodel.cn/api/anthropic`），常用来让 Claude Code 跑 GLM；GLM-5 / 5.2 / 5.3 的 Terminal-Bench、ProgramBench、CyberGym 等成绩都是在 Claude Code 中测得。
- **GLM Coding Plan**：面向编码工具的包月订阅（本次未读官方页，价格未核实）。
- **ZCode**：2026-07 自有桌面编码应用。
- **slime**：GLM-5 使用的异步强化学习训练框架（THUDM/slime）。

### 5. 与阿里生态的关系

- 资本：阿里巴巴是 2023 年融资的投资方之一。
- 分发：2026-05-20 起阿里云百炼可通过统一 API 调用 GLM-5.1。
- 框架：AgentScope 与 Spring AI Alibaba 的官方模块未单列智谱，可通过 OpenAI 兼容接口或百炼接入（整理者归纳）。
