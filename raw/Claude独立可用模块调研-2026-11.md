# Claude 生态可独立使用的项目与模块调研（2026-11）

一句话：逐个查看 Anthropic 及其关联组织（anthropics、anthropic-experimental、safety-research、modelcontextprotocol、agentskills）在 GitHub 上的公开项目，以及 Claude Code 官方文档里关于第三方提供商、网关、遥测的说明，判断哪些能脱离 Anthropic 的服务（Claude API、claude.ai 账号、Anthropic 云端）独立使用，并分析能独立使用的模块的原理。资料来自 GitHub API 与 README、npm / PyPI 元数据、code.claude.com 文档的 Markdown 版本、Ollama 与 DeepSeek 官方文档、Anthropic 博客，检索日期 2026-11-05。

"独立"分两种：一是**不需要 Claude 模型**（换别家模型或本地模型也能用），二是**需要 Claude 模型但不经 Anthropic 自己的服务**（走 Amazon Bedrock、Google Cloud、Microsoft Foundry 等云厂商）。本文主要讨论第一种，第二种单独标出。

## 官方文档摘录

### Claude Code 的协议与部署

- 仓库 LICENSE.md："© Anthropic PBC. All rights reserved. Use is subject to Anthropic's Commercial Terms of Service."（npm 包的 license 字段为 `SEE LICENSE IN README.md`；仓库只放文档、插件示例和 issue，不是源码）
- 部署选项（third-party-integrations）：Claude for Teams / Enterprise、Anthropic Console、Amazon Bedrock、Claude Platform on AWS、Google Cloud's Agent Platform（原 Vertex AI）、Microsoft Foundry，另有自托管的 Claude apps gateway
- "LLM Gateway: A service that sits between Claude Code and the cloud provider to handle authentication and routing."
- llm-gateway："Any gateway that exposes a supported API format works. Anthropic doesn't endorse, maintain, or audit third-party gateway products, and doesn't support routing Claude Code to non-Claude models through any gateway."
- 网关可用的三种 API 格式：Anthropic Messages（`ANTHROPIC_BASE_URL`，端点 `/v1/messages`、可选 `/v1/messages/count_tokens`）、Amazon Bedrock InvokeModel（`CLAUDE_CODE_USE_BEDROCK=1` + `ANTHROPIC_BEDROCK_BASE_URL`）、Google Cloud rawPredict（`CLAUDE_CODE_USE_VERTEX=1` + `ANTHROPIC_VERTEX_BASE_URL`）；Foundry 和 Claude Platform on AWS 也是 Messages 格式
- "Token-counting endpoints are the only optional ones: when they're absent, Claude Code falls back to a character-based estimate of context usage."
- "Anthropic Messages format: the developer sets `ANTHROPIC_BASE_URL` to your gateway. Claude Code treats the gateway as the Claude API and can't tell which upstream you forward to."
- 流式要求：网关不能缓冲整个响应；Claude Code 需要完整事件序列直到 `message_delta` 和 `message_stop`；长时间无字节会触发空闲超时
- fast mode 的可用性检查 "calls `api.anthropic.com` directly rather than following `ANTHROPIC_BASE_URL`"
- `allowedProviders`（托管设置）可限制机器只用某个提供商，例如 `["customEndpoint"]` 只允许 `ANTHROPIC_BASE_URL` 指向的网关
- Claude apps gateway："It is included in the `claude` binary, so the same executable that runs Claude Code on a laptop runs the gateway server with `claude gateway --config gateway.yaml`."
- "The gateway's own data plane sends nothing to Anthropic infrastructure unless the Anthropic API is a configured upstream."
- 自托管环境（公测，Team / Enterprise）：云端会话在自己的 runner 上执行，但队列、会话流和推理仍在 api.anthropic.com，由 Anthropic 控制面调度

### Claude Code 的遥测与外联

- "Claude Code sends two kinds of operational telemetry: usage metrics and error reports."
- 指标："Metrics never include your code, prompts, or file paths. Set `DISABLE_TELEMETRY=1` to opt out."；错误报告用 `DISABLE_ERROR_REPORTING=1` 关闭；`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` 一次关闭所有非必要流量
- "By default, error reporting, telemetry, and bug reporting are disabled when using Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, or Claude Platform on AWS."
- 使用第三方提供商或没有 Anthropic 凭据时，`/feedback` 把报告写到本地 `~/.claude/feedback-bundles/`
- WebFetch 域名安全检查："Before fetching a URL, the WebFetch tool sends the requested hostname to `api.anthropic.com`"；"This check runs regardless of which model provider you use and is not affected by `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`."，用 `skipWebFetchPreflight: true` 关闭
- 会话质量调查不论提供商默认开启，`CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1` 关闭

### Sandbox Runtime（srt）

- "A lightweight sandboxing tool for enforcing filesystem and network restrictions on arbitrary processes at the OS level, without requiring a container."
- "`srt` uses native OS sandboxing primitives (`sandbox-exec` on macOS, `bubblewrap` on Linux) and proxy-based network filtering. It can be used to sandbox the behaviour of agents, local MCP servers, bash commands and arbitrary processes."
- "The Sandbox Runtime is a research preview developed for Claude Code to enable safer AI agents."
- Windows：在专用本地账户 `srt-sandbox` 下运行，用 Windows Filtering Platform 按该账户 SID 做出站过滤，配合写受限令牌
- "Both filesystem and network isolation are required for effective sandboxing."
- 文件读取默认允许、可 deny 后再 allow；写入默认全部拒绝，只能显式允许；网络默认全部拒绝，只能按域名放行
- Linux："The network namespace of the sandboxed process is removed entirely, so all network traffic must go through the proxies running on the host (listening on Unix sockets that are bind-mounted into the sandbox)"
- macOS："The Seatbelt profile allows communication only to a specific localhost port."
- HTTP/HTTPS 走 HTTP 代理，其他 TCP 走 SOCKS5 代理，代理执行域名白名单 / 黑名单
- 可当 CLI（`srt <命令>`，配置 `~/.srt-settings.json`）、库（`SandboxManager.initialize` + 包装命令）、独立代理（`srt proxy`）；`--control-fd` 运行中热更新网络规则（文件规则不能热更新）
- 典型用法：在 `.mcp.json` 里把 `command` 改成 `srt`，给本地 MCP 服务器加沙箱

### Agent Skills 与 Anthropic 的 skills 仓库

- agentskills.io："Agent Skills are a lightweight, open format for extending AI agent capabilities with specialized knowledge and workflows."
- "The Agent Skills format was originally developed by Anthropic, released as an open standard, and has been adopted by a growing number of agent products."

### MCP Bundles（MCPB，原 DXT）

- "MCP Bundles (`.mcpb`) are zip archives containing a local MCP server and a `manifest.json` that describes the server and its capabilities."

- 仓库包含三部分：规范 MANIFEST.md、打包 CLI（`mcpb init`、`mcpb pack`）、Claude 桌面端加载与校验 bundle 的代码

### 可解释性工具

- circuit-tracer："This library implements tools for finding circuits using features from (cross-layer) MLP transcoders"；三项功能：计算归因图、可视化与标注、对 transcoder 特征做干预；支持 Gemma-2（2B）、Llama-3.2（1B），Neuronpedia 上另有 Qwen3-4B 的 transcoder；Gemma-2 2B 可在 Colab 免费 GPU 上运行
- jacobian-lens："The Jacobian lens reads out what an internal activation is disposed to make the model say."；公式 `lens_l(h) = unembed( J_l @ h ), J_l = E[∂h_final / ∂h_l]`；"This repo fits the lens on open-weights decoder transformers"；约 100 条提示即可拟合出可用的 lens；Apache-2.0，不维护

### 对齐评测工具

- Petri（现为 Inspect Petri）："an auditing agent that enables automated monitoring and interaction with language models to detect potential alignment issues, reward hacking, and other concerning behaviors."；生成审计场景、编排审计模型与目标模型的多轮对话、模拟工具与回滚、由评判模型按统一量表打分
- 捐赠公告（2026-05-07）：交给 AI 评测非营利组织 Meridian Labs，"will help ensure that Petri remains independent of any AI lab"；3.0 把审计模型和目标模型拆成可分别调整的组件，并与 Bloom 集成
- Bloom："Bloom generates evaluation suites that probe LLMs for specific behaviors (sycophancy, self-preservation, political bias, etc.)"；仓库已冻结，"It is now developed and maintained by Meridian Labs"
- safety-tooling："provides an LLM API with a common interface for OpenAI, Anthropic and Google models."

### 第三方 Anthropic 兼容端点

- Ollama：连接 "Anthropic clients and tools such as Claude Code to Ollama"；本地配置 `ANTHROPIC_AUTH_TOKEN=ollama`、`ANTHROPIC_BASE_URL=http://localhost:11434`；快捷命令 `ollama launch claude`；不支持 `count_tokens`、`tool_choice`、`metadata`、提示缓存、Batches、Citations、PDF、流内错误事件；`budget_tokens` 接受但不执行
- DeepSeek："our API has added support for the Anthropic API format"，基础地址 `https://api.deepseek.com/anthropic`；`anthropic-version`、`cache_control`、`mcp_servers`、`citations` 等字段被忽略；`document`、`search_result`、`redacted_thinking`、`mcp_tool_use` 等内容块不支持

## 检索要点（二手整理，非逐字）

- **Claude Code 接非 Claude 模型**：社区普遍用 `ANTHROPIC_BASE_URL` + `ANTHROPIC_AUTH_TOKEN` 指向提供 Anthropic 兼容端点的服务，并用 `ANTHROPIC_MODEL` 等变量把 Opus / Sonnet / Haiku 档位映射到对方模型。常见目标：DeepSeek（`api.deepseek.com/anthropic`）、智谱 GLM（`api.z.ai/api/anthropic`，国内 `open.bigmodel.cn/api/anthropic`）、Kimi（Moonshot 有多个地址，资料不一致）、MiniMax、Qwen、OpenRouter、LM Studio、Ollama（v0.14.0 起，2026-01）。一份兼容性目录称 20 家提供商中有 12 家提供 Messages 兼容端点。本地模型需要较大的上下文窗口。官方明确不支持这种用法。
- **Claude Code 源码泄露**：2026-03-31，npm 包 2.1.88 误带约 60MB 的 source map，可还原出完整 TypeScript 源码（各报道的文件数不一，约 1,900 个）。Anthropic 撤下该版本，称是发布打包的人为失误，没有客户数据或凭据泄露。泄露不改变协议：代码仍是专有的。
- **Petri 与 Bloom**：Petri 2025-10 发布，Bloom 随后发布；2026-05-07 两者交给 Meridian Labs（Inspect、Inspect Scout 也在该组织），Petri 3.0 基于 Inspect 框架，审计模型、目标模型、评判模型都可以换成任意 Inspect 支持的提供商。有评论质疑 Meridian Labs 相对 Anthropic 的独立程度。
- **circuit-tracer**：2025-05 随 Anthropic 开源“电路追踪”工具发布，由 Anthropic Fellows 项目成员开发，与 Neuronpedia 合作提供在线界面；仓库现归 decoderesearch 组织。
- **Agent Skills 治理**：agentskills.io 称格式由 Anthropic 发起、作为开放标准发布、接受社区贡献；未找到它已捐给 Agentic AI Foundation 的一手证据（AAIF 的创始项目是 MCP、goose、AGENTS.md）。

## 依赖分级（调研结论）

- **完全独立（不需要 Claude，也不连 Anthropic 服务）**：MCP 规范与各语言 SDK、Inspector、Registry（2025-12 捐给 Linux Foundation 下的 AAIF）、MCP Bundles 格式与 CLI、Agent Skills 格式（agentskills.io）及 skills 仓库里 Apache-2.0 的示例技能、Sandbox Runtime（srt）、Claude 宪法（CC0）、circuit-tracer、jacobian-lens、persona_vectors、Petri / Bloom（已交给 Meridian Labs）、safety-tooling、hh-rlhf 与 evals 等数据集、political-neutrality-eval、buffa、claudes-c-compiler、FlashProve、Bun
- **只是一种格式或做法，可搬到别的工具**：Claude Code 插件格式（技能 + 子 Agent + Hooks + MCP 服务器的目录约定）、CLAUDE.md 项目指令、single-agent-loop-kit 的评测方法（自带离线假模型）
- **需要 Claude，但可以不经 Anthropic 自家服务**：Claude Code、Claude Agent SDK、claude-code-action、claude-code-security-review、defending-code-reference-harness——都能走 Amazon Bedrock、Google Cloud、Microsoft Foundry、Claude Platform on AWS，或自托管的 Claude apps gateway；走云厂商时遥测、错误报告、`/feedback` 默认关闭
- **能改配置接非 Claude 模型，但官方不支持**：Claude Code / Agent SDK 把 `ANTHROPIC_BASE_URL` 指向 Ollama、DeepSeek、GLM、Kimi 等 Anthropic 兼容端点；官方 SDK（Apache-2.0）改 `base_url` 也一样。代价是提示缓存、token 计数、引用、PDF、服务端工具等 Anthropic 专有特性失效，WebFetch 域名检查仍会访问 api.anthropic.com
- **离不开 Anthropic**：claude.ai 与 Claude 桌面端、Claude Code 云端会话（含自托管 runner，控制面和推理仍在 Anthropic）、Claude Developer Platform 的服务端功能（Files、Batches、Skills API、托管 Agent）、claude.ai 订阅登录、Claude Security 与 OSS Scanner 服务、docx / pdf / pptx / xlsx 文档技能（协议限定用于 Anthropic 服务）
