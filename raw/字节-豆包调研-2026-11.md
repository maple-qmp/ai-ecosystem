## 整理

### 1. 组织与产品结构

- **Seed 团队**：字节跳动的大模型研究团队，负责豆包大模型、Seedream（图像）、Seedance（视频）、Seed-OSS、UI-TARS 等。
- **火山引擎**：字节的云服务，对外提供豆包大模型 API（火山方舟），也代理第三方模型。2026-06 FORCE 大会引用 IDC 数据，称火山引擎在中国公有云 MaaS 市场份额 49.5%，排名第一。
- **豆包 App**：面向国内的 AI 助手；海外版先叫 Cici，后改名 Dola。
- **开发者产品**：Coze（扣子，Agent 搭建平台，2025-07 开源 Coze Studio 与 Coze Loop，Apache-2.0）、TRAE（AI IDE，Seed 2.0 Pro 与 Code 模型首发入口之一）、Eino（Go 语言 LLM 应用框架，先于 Coze 开源）。

### 3. 定价曲线

- 2024-05 首发：豆包 Pro 32K 输入 0.0008 元 / 千 token（0.8 元 / 百万），比当时行业均价低约 99%，是 2024 年国内价格战的起点。
- 2025：1.5 Pro 维持 0.8 元 / 百万输入；1.6 起按输入长度分段计价。
- 2026-06：Seed 2.1 Pro 输入 6 元 / 百万 token，价格明显上调，报道称这是“告别价格战”。

### 4. 开放程度

- 豆包 / Seed 主力模型（1.5、1.6、1.8、2.0、2.1）**不开放权重**，只通过火山引擎 API 和自有产品提供。
- 开放权重的是中小模型与研究模型：UI-TARS（2B / 7B / 72B）、Seed-Coder-8B、Seed-OSS-36B、BAGEL-7B、SeedVR、Seed-X 翻译模型等，多为 Apache-2.0 或 MIT。

### 5. 与阿里生态的关系

字节与阿里是直接竞争关系，没有股权往来：火山引擎（豆包）对阿里云百炼（通义 / Qwen），豆包 App 对千问 App，Coze 对阿里的百炼应用与 AgentScope。框架层面，AgentScope（Python）把 Volcengine 列为内置模型提供方。
