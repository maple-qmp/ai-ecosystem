## 整理

### 1. 公司概况

- 2023-03 在北京成立，创始人杨植麟、周昕宇、吴育昕（清华同学）。产品品牌 Kimi，海外域名 kimi.com / kimi.ai，API 平台 platform.moonshot.ai。
- 主要股东：阿里巴巴（2024-02 领投）、腾讯（2024-08 起）、IDG、高榕等。
- 研究与基础设施：Mooncake 推理服务架构（以 KV Cache 为中心，获 USENIX FAST 最佳论文）、Muon 优化器的规模化（Moonlight 16B-A3B）、Kimi Delta Attention（KDA，线性注意力）。

### 3. 许可证演变

- K2 / K2 Thinking / K2.5 / K2.6 / K2.7 Code：Modified MIT。唯一附加条件是月活超 1 亿或月收入超 2000 万美元的商业产品要在界面上显著标注 “Kimi K2”。
- K3 / K3.1 Pro：自定义 Kimi K3 License。新增 “模型即服务（MaaS）” 条款：MaaS 业务方及其关联方连续 12 个月总收入超过 2000 万美元的，商用前需与月之暗面另签协议；内部使用、通过官方产品或认证推理伙伴使用不受此限。标注要求保留。
- 小模型（Moonlight、Kimi-VL、Kimi-Audio、Kimi-Dev、Kimi Linear）均为标准 MIT。

### 4. 与阿里生态的关系

- 资本：阿里巴巴 2024-02 领投，此后持续持股。
- 分发：2026-05-20 起阿里云百炼可通过统一 API 调用 Kimi K2.6（与 GLM-5.1、MiniMax M2.7 同批）。
- 框架：AgentScope Python 版把 Moonshot 列为内置模型提供方；AgentScope Java 2.0 和 Spring AI Alibaba 官方模块只列 DashScope、OpenAI、Anthropic、Gemini、Ollama 等，Kimi 需通过 OpenAI 兼容接口或百炼接入（整理者归纳）。
- 算力：2026-07 有报道称阿里云提供 H200 集群，阿里否认。
