# AI算力与硬件调研（2026-11）

一句话：梳理 L0 层的算力与硬件，分五块。一是 NVIDIA 之外的加速器——Google TPU、AMD Instinct、华为昇腾、AWS Trainium / Inferentia、Groq LPU、Cerebras 晶圆级芯片；二是与之配套的软件栈 CUDA、ROCm、CANN、Neuron；三是三大云厂商（AWS、Azure、Google Cloud）的 AI 算力服务与自研芯片；四是 CoreWeave、Nebius 这类专做 GPU 出租的「新云」；五是 Stargate 等以吉瓦（GW）为单位的大型数据中心项目。检索日期 2026-11-05。

## 一、NVIDIA 与 CUDA

- 财务规模（二手报道）：FY2027 Q2（截至 2026-07-26）总营收 962 亿美元、同比 +106%，其中数据中心 890 亿美元、同比 +117%，占比超过 92%；GAAP 营业利润 637 亿美元；下季指引 1080 亿美元，且**假设中国数据中心计算业务营收为零**。
- 产品节奏（二手报道）：2025 年出货 GB300（Blackwell Ultra）；Vera Rubin 平台 2025-10 在 GTC Washington 首次展示，黄仁勋称 2026 下半年量产；NVIDIA 宣称 NVL144 的 FP4 推理 3.6 EFLOPS、FP8 训练 1.2 EFLOPS，为 GB300 NVL72 的 3.3 倍（厂商数字）。报道中机架名称 NVL144 与 NVL72 混用，前者按计算裸片数、后者按封装数计；Rubin Ultra 预计 2027 下半年。AWS、Google Cloud、Azure、OCI、CoreWeave、Lambda、Nebius、Nscale 均宣布 2026 下半年提供 Vera Rubin 实例。
- CUDA Toolkit 13.0（2025-08，二手报道 + NVIDIA 博客搜索摘要）：在传统 SIMT 之外铺设第二条路线——基于 tile 的编程模型，引入 CUDA Tile IR 后端；统一 Arm 工具链（服务器与嵌入式合并）；向量类型改为 32 字节对齐以利 Blackwell；新增 GCC 15 / Clang 20 支持，去掉 ICC 与 MSVC 2017。后续 13.1 推出 CUDA Tile 与 cuTile Python（Apache-2.0）。这是 CUDA 二十年来编程模型层面最大的一次变化，动机是让 Python 侧也能写出接近内核水平的性能，正面对冲 Triton、TileLang 等第三方 DSL。
- Groq 许可（二手报道）：2025-12 下旬 NVIDIA 与 Groq 达成非排他的推理技术许可，报道金额约 200 亿美元；Groq 创始人 Jonathan Ross 与总裁 Sunny Madra 加入 NVIDIA，Groq 作为公司独立存续、继续运营 GroqCloud。首个产物是 Groq 3 LPX 推理系统（256 颗 LPU、液冷）。参议员 Warren 与 Blumenthal 就该交易是否规避并购申报规则致信 FTC。细节（工程师比例、后续融资）在各来源间互相矛盾，未核实。

## 二、Google TPU

- TPU 是 Google 自研的 AI 加速器，与开源编译栈 XLA、框架 JAX 配套；JAX README 原文：「JAX uses XLA to compile and scale your NumPy programs on TPUs, GPUs, and other hardware accelerators.」（一手）
- 第七代 Ironwood（二手报道）：2025-11 发布，规格为每颗 192 GB HBM、约 7.37 TB/s 带宽、4,614 TFLOPS（FP8）；完整 pod 9,216 颗芯片、通过 3D torus 互联、共享约 1.77 PB 内存；定位推理，宣称能效为上一代的两倍。GA 日期各来源不一（2025-11、2026-03-31、2026-04-22 三说），需按 Google Cloud 公告核实。
- 第八代（二手报道）：Google 预览把 TPU 拆成 TPU 8t（训练）与 TPU 8i（推理）两条产品线，均用台积电 2nm，目标 2027 年底；同时推出自研 Arm CPU Axion 承接通用负载。
- 锚定客户 Anthropic（**一手**，Anthropic 2025-10-23 博客）：Anthropic 计划把 Google Cloud TPU 用量扩大到「up to one million TPUs」，预计 2026 年上线「well over a gigawatt of capacity」；博客同时写明 Anthropic「efficiently uses three chip platforms–Google's TPUs, Amazon's Trainium, and NVIDIA's GPUs」，并强调 Amazon 仍是其主要训练伙伴与云厂商。交易金额为「数百亿美元」量级，未披露确数。
- 开源推理侧（一手，GitHub）：vLLM 的 TPU 支持由独立仓库承担，`vllm-project/tpu-inference` 已改名 vLLM JAX（`vllm-jax`），专注在 TPU 上用 vLLM 服务 JAX 模型；PyTorch 原生的 TPU 服务另分出 `vllm-torchtpu`。SGLang 侧有 SGLang-TorchTPU 与 SGL-JAX 两条路径（见本库已有的推理引擎调研）。
- 原文摘录（一手）：
  - 「`tpu-inference` is now vLLM JAX (`vllm-jax`) and is focused on serving JAX models on TPU with vLLM.」—— vllm-project/tpu-inference README
  - 「including up to one million TPUs」「is expected to bring well over a gigawatt of capacity online in 2026」—— Anthropic 博客

## 三、AMD Instinct 与 ROCm

- ROCm（一手，GitHub README）：AMD 的开源 GPU 计算软件栈，涵盖驱动、开发工具与 API；核心是 HIP——一套 C++ 运行时 API 与内核语言，接口刻意贴近 NVIDIA CUDA，便于移植；另支持 OpenMP 与 OpenCL，集成 PyTorch、TensorFlow。README 顶部已声明该仓库即将弃用，后续开发与 issue 迁往 `ROCm/TheRock`。
- ROCm 7（二手报道）：2025-06 在 Advancing AI 上公布，AMD 宣称推理能力为 ROCm 6 的 3.5 倍、训练 3 倍（厂商数字），新增 Radeon 消费级 GPU 支持；2025-09 中旬 7.0 正式发布，含 HIP 7.0；7.1 于 2025-10 下旬打标签，7.2 于 2026-01，7.2.1 支持 Ubuntu 24.04.4 LTS。同期推出 AMD Developer Cloud，提供 MI300X 的免费额度。工具链上 ROCm SMI 进入维护模式，ROCTracer / ROCProfiler / rocprofv2 在 2026 年初前让位给 ROCprofiler-SDK。
- Instinct MI400 / MI450 系列（二手报道）：CDNA 5 架构、HBM4，台积电 2nm；报道规格为 432 GB HBM4（MI350 为 288 GB HBM3E）、19.6 TB/s 带宽；分 MI455X（训练 + 推理）与 MI430X（HPC 与主权 AI）两档；配套机架级平台 Helios（MI450X IF128，128 颗 GPU 一机架），对标 NVIDIA VR200 NVL144。AMD 已向头部客户送样，量产与 Helios 系统目标 2026 下半年；AMD 否认 MI455X 延期的报道。MI500（CDNA 6、HBM4E）预计 2027。
- 客户（二手报道）：Oracle 计划自 2026 年底起在 OCI 部署 5 万颗 MI450；OpenAI 预计是首批客户之一；Anthropic 的相关传闻只见于单一来源，未证实。AMD 管理层称最大规模的部署用于推理。
- 生态位置：ROCm 被 vLLM、SGLang、llama.cpp（HIP 后端）等主流引擎支持，是 CUDA 之外唯一在数据中心形成规模的通用 GPU 栈；短板仍是内核库与长尾算子的成熟度。

## 四、华为昇腾与 CANN

- 昇腾（Ascend）是华为的 AI 加速器系列（一手，TorchNPU README 原文：「Ascend NPU (Neural Processing Unit) is a series of AI accelerators developed by Huawei.」）。软件栈分三层：底层 CANN（算子与运行时）、框架适配 TorchNPU（PyTorch 的 Ascend 适配插件，BSD-3-Clause，PyPI 包 `torch-npu`）与自研框架 MindSpore（昇思）。
- TorchNPU 近况（一手）：2026-04-30 发布 26.0.0，支持 PyTorch 2.10.0、Python 3.13、P2P 通信组分派、DTensor 策略扩展等；仓库同时托管在 GitCode 与 GitHub；PyPI 最新 2.14.0（2026-10-15）。
- 推理侧（一手）：`vllm-project/vllm-ascend` 是 vLLM 的社区维护硬件插件，README 原文「vLLM Ascend (`vllm-ascend`) is a community maintained hardware plugin for running vLLM seamlessly on the Huawei Ascend NPU.」，是 vLLM 社区支持昇腾的推荐路径；2026-10 发布 v0.30.0。llama.cpp 亦有 CANN 后端。
- 路线图（二手报道，Huawei Connect 2025-09 徐直军演讲）：Ascend 950 系列分 950PR（面向预填充与推荐，2026 Q1）与 950DT（面向解码与训练，2026 Q4），同一 Die、分别配自研 HBM HiBL 1.0 与 HiZQ 2.0；Ascend 960 为 2027 Q4、970 为 2028 Q4。超节点 Atlas 950 SuperPoD 最大 8,192 颗 950DT（2026 Q4），宣称 8 EFLOPS（FP8）/16 EFLOPS（FP4）、16 PB/s 互联带宽；Atlas 950 SuperCluster 为 64 个超节点、52 万颗以上芯片；Atlas 960 SuperPoD 1.5 万余颗（2027 Q4），SuperCluster 规划百万颗、2 ZFLOPS（FP8）。公开展示的实机规模（1,024 张加速卡）远小于最大配置。华为自研 HBM 与产能是这张路线图最大的不确定项。
- CANN 开源（二手报道）：2025 年华为宣布计划在 2025 年底前开源 CANN；到 2026 年鲲鹏昇腾开发者大会（KADC2026）口径为「CANN 全面开源开放」，已开放 50 多个代码仓、800 多个算子，兼容 PyTorch、vLLM 等框架与 Triton、TileLang 等生态语言；2026-08-15 CCF 中国开源大会设「CANN 全面开源开放」分论坛，讨论昇腾 950 架构与 DeepSeek V4 的优化实践。开源范围未见官方清单。
- 与中国模型的关系（二手报道，口径互相矛盾，需谨慎）：

## 五、AWS Trainium / Inferentia 与 Neuron

- Neuron SDK（一手，README 原文）：「AWS Neuron is a software development kit (SDK) enabling high-performance deep learning and generative AI using AWS Inferentia and Trainium accelerators.」支持 Inf1、Inf2、Trn1、Trn2、Trn3 实例；包含图编译器、运行时、开发工具（Neuron Explorer、agentic 开发工具），集成 PyTorch、JAX 与 vLLM Neuron；Neuron Kernel Interface（NKI）提供直接编写 NeuronCore 内核的能力。Inferentia 面向推理、Trainium 面向训练，近年两条线在宣传上逐渐合并到 Trainium。
- Trainium3（二手报道）：2025-12-02 re:Invent 2025 上 Trn3 UltraServer 正式可用，每系统最多 144 颗芯片、合计 362 PFLOPS（FP8），AWS 称算力为 Trainium2 一代的 4.4 倍，是 AWS 首颗 3nm AI 芯片；机内互联换成 NeuronSwitch-v1，带宽约翻倍，Enhanced Neuron Fabric 把芯片间通信延迟压到 10 微秒以内。早期客户含 Anthropic、Ricoh、Splash Music 等；Amazon Bedrock 的生产负载已跑在 Trainium3 上。
- Trainium4（二手报道）：同场预览，AWS 称 FP8 性能至少为 Trainium3 的 3 倍、内存带宽 4 倍，并将支持 NVIDIA NVLink Fusion 互联；无明确时间表。
- Project Rainier（二手报道）：为 Anthropic 建设的 Trainium2 集群，2025-10 投入使用，7 栋建筑、近 50 万颗 Trainium2，目标扩到 100 万颗；每台机器 4 台服务器、每服务器 16 颗芯片，用自研 NeuronLink 互联。
- AWS 的第三方算力（二手报道）：2025-11-03 与 OpenAI 签七年、约 380 亿美元协议，OpenAI 通过 EC2 UltraServers 使用 GB200 / GB300 集群，用于 ChatGPT 推理与模型训练，立即起用、2026 年底达到满容量；同时微软失去 OpenAI 算力的优先购买权。Cerebras 的 WSE-3 也将部署进 AWS 数据中心（「分离式架构」，二手报道）。

## 六、Groq 与 Cerebras

- Groq（二手报道）：自研 LPU（Language Processing Unit），架构特点是用大容量片上 SRAM 替代 HBM、确定性调度，强项是低延迟 token 生成，只做推理不做训练；GroqCloud 提供 OpenAI 兼容的推理 API，官方 Python SDK 由 Stainless 生成（一手，README）。2025-12 与 NVIDIA 的非排他许可见上文；公司称独立运营，由 Simon Edwards 接任负责人，全球 13 个数据中心（后两条为单一来源，未证实）。
- Cerebras（二手报道 + 一手 README）：做晶圆级芯片 WSE-3（整片晶圆一颗芯片，以巨大的片上内存与带宽避开 HBM 瓶颈），面向训练与超低延迟推理；Model Zoo 是其官方参考实现与 CLI（一手，README：「collection of deep learning models and utilities optimized to run on Cerebras hardware」）。2026-04 递交 S-1，2026 年完成纳斯达克 IPO，定价 185 美元/股、高于 150–160 美元区间，募资约 55.5 亿美元，为 2026 年美股最大科技 IPO；估值口径从约 400 亿到首日翻倍后的 950 亿–1000 亿美元不等，须按招股书核实。OpenAI 承诺采购 750 MW 推理算力（报道金额 100 亿或 200 亿美元以上，口径不一），并有到 2030 年追加 1.25 GW 的选择权，Cerebras 向 OpenAI 发行最多 3,340 万股认股权证。客户集中度是其主要风险：此前某财年 62% 收入来自阿联酋的 MBZUAI，另有报道称阿联酋客户占 2025 年收入约 86%。
