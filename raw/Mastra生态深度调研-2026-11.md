## 检索要点（二手整理，非逐字）

### 公司与融资

- 2024 年成立，总部旧金山，团队分布全球。创始人：Sam Bhagwat（CEO）、Abhi Aiyer（CTO）、Shane Thomas（CPO），三人均来自 Gatsby（前端框架，后被 Netlify 收购）。多份二手资料称团队起初想做 AI CRM，后转做框架（关于页未提及）。
- Y Combinator 2025 冬季批次（W25）。2025-02 首次在 Hacker News 发帖介绍 Mastra。
- 2025-10-08：1300 万美元种子轮，Y Combinator、Gradient Ventures 及 120 多位天使投资人参与，包括 Paul Graham、Guillermo Rauch。
- 2026-04-09：2200 万美元 A 轮，Spark Capital 领投，累计融资 3500 万美元（关于页列出的投资方含 Spark Capital、Gradient、basecase、Y Combinator）；同周发布 Mastra Platform。未见公开估值。

### 开源框架 Mastra

- TypeScript 编写，npm 核心包 `@mastra/core`，脚手架 `npm create mastra@latest`。仓库 mastra-ai/mastra，约 2.93 万星、3100 fork（2026-11）。协议：主体 Apache-2.0，`ee/` 目录下代码使用 Mastra Enterprise License（开发测试免费，生产需授权）。
- 2026-01-21 发布 1.0 稳定版（Show HN 与 Product Hunt 同日）。当时每周 npm 下载 30 万+、1.94 万星；生产用户举例 Replit、PayPal、Sanity、WorkOS。2025-02 到 1.0 之间加入：原生模型路由（40+ 厂商、600+ 模型）、低延迟护栏（提示注入、PII 脱敏、内容审核）、scorers（异步评测）、带单次调用成本的 AI 追踪、memory processors、`.network()` 多 Agent 路由、Express / Hono 服务器适配器。Playground 一度移除，后以 Studio 名义回归。
- 与 Vercel AI SDK 的关系：早期借用 AI SDK 做模型路由，后来改为自带模型路由；创始人称 AI SDK 更底层，Mastra 与存储、Studio、评测、记忆集成更紧。
- 版本发布频繁：一份第三方页面列 `@mastra/core` 1.78.0（2026-10-15），未在一手页面核实。
- 文档中的主要原语（2026-11）：
  - Agents：工具、结构化输出、人工审批、护栏、processors
  - Workflows：类型化多步流程，分支、并行、循环、suspend / resume、快照、时间旅行、定时
  - Harness：超出单次请求的持久执行，含目标、定时、后台任务和 Agent Controller
  - Memory：消息历史、语义召回、working memory、observational memory
  - Knowledge：带作用域与权限的托管内容；RAG（分块、嵌入、检索、向量库、GraphRAG）
  - 子 Agent、Skills、Channels（消息平台）、Signals（事件流、跨进程信号）
  - Sandboxes / Workspaces：文件系统、搜索、shell、computer use、LSP
  - Connections：MCP、A2A、ACP
  - Evals：内置、规则与自定义 scorer，CI、Vitest、数据集、实验
  - Observability：层级追踪、日志、反馈、指标，可导出到外部平台
  - Server：框架适配器、中间件、PubSub、客户端 SDK；Studio 可视化界面；Auth；Voice（STT / TTS / 语音到语音）
  - 前端集成：Next.js、React + Vite、Astro、Express、SvelteKit、Hono
- Observational Memory（2026-02-09 文章）：主 Agent 旁运行两个后台 Agent，Observer 把对话压缩成带日期、带优先级的观察日志，Reflector 定期再压缩；主 Agent 直接从上下文读日志，不按轮检索。LongMemEval（longmemeval_s）自报成绩：gpt-5-mini 94.87%、gemini-3-pro-preview 93.27%、gpt-4o 84.23%；多会话类问题最弱（最好 87.2%）。
- Agent Controller（2026-10-06 GA）：托管长时、可交互 Agent 会话的运行时，包在 Agent 循环外，让会话保持打开、可观察、可中断和引导；每个用户一个会话，独立的线程、模式、模型、审批、记忆和子 Agent。最初为 Mastra Code 而建，后扩展到 Mastra Factory；GA 前由 Harness 更名为 `AgentController`。
- MCP（2026-10-21）：`@mastra/mcp` 2.0 支持 MCP 2026-07-28 规范：去掉 `initialize` 握手与 `Mcp-Session-Id`；支持 `Mcp-Method` / `Mcp-Name` 头、列表缓存提示（`ttlMs`、`cacheScope`）、`server/discover`、`requestState`（工具可 `suspend()` 向调用方提问）、`progress()`；移除 SSE 传输、roots、sampling、动态客户端注册，只接受 2026-07-28 客户端；暂不支持 tasks。2026-10-23 另发布 MCP Events 支持。

### 商业平台 Mastra Platform

- 2026-04 与 A 轮同周推出（此前称 Mastra Cloud）。功能：托管部署、环境、可观测性、告警、数据库、workspaces、Studio。
- 计费（2026-07-17 说明）：所有费用（含模型与 token）走统一积分池。Starter 免费、按量付费，每月含 10 万观测事件、24 CPU 小时、10GB 出口流量，数据保留 15 天，项目与部署不限；Team 250 美元 / 月，含 100 万事件、250 CPU 小时、100GB，保留 6 个月，加多团队、SSO、SOC 2；Server Always-On 每项目 100 美元；Enterprise 定制（RBAC、审计日志、SLA）。
- 2026-10 密集发布：Thread View、Metrics API、Trace Imports、Trace Queries、Studio 级 SSO、Span Queries；2026-10-21 发生平台事故并发布事故报告。

### 应用产品

- **Mastra Code**（2026-02-24 发布）：开源终端编程 Agent，用 observational memory 代替上下文压缩（compaction）。plan / build 模式，LSP 与 ast-grep 的 AST 感知编辑，shell、搜索、网页搜索，可用不同模型的子 Agent，skills，支持 Claude Max / ChatGPT Plus 登录或 API key，项目级持久会话与 worktree，通过模型路由可用约 1800 个模型，工具审批与 YOLO 模式，本地 LibSQL（SQLite）存储。
- **Mastra Factory**（2026-07-27 公布，2026-09-08 公开测试）：开源、Agent 驱动的软件交付环境，在自控的 Web 应用中运行持久编程 Agent，流程为 Intake → Triage → Planning（人工批准计划）→ Building（独立 workspace，产出 PR）→ Review → Done；每阶段可手动或自动；可用 Signals 中途引导；集成 GitHub、Linear、Slack；可托管或自托管。Mastra 自报：自 7 月起 Factory 在自家仓库写了 25–35% 的 PR、关闭 50–60% 的 issue。
- **Mastra Knowledge**（2026-10-26，早期访问）：独立服务，存放公司与团队上下文，连接 Slack、Monday 等，在 Agent 需要时提供；与负责用户级、线程级上下文的 Mastra memory 并列。

### 商业项目

- Mastra Agency Program（2026-10-08）：面向代理商 / 服务商的合作计划。
- Mastra Launch（2026-10-20）：给已在用 Mastra 的团队提供企业版平台权限和前线部署工程师（FDE）每周驻场支持，目标 90 天内上线；只收实施费，90 天未上线则只付实施费。
