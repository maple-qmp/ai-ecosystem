# AI 应用产品调研（2026-11）

一句话：补全 L5 应用层，按四组整理十个面向终端用户的 AI 产品，并核实三个已有的编程类应用页。四组是：对话助手 ChatGPT、Claude 应用（claude.ai）、Gemini App、豆包 App、Kimi App；AI 搜索 Perplexity；编程 Agent Devin、Windsurf（2026-06 改名 Devin Desktop），以及已有的 Claude Code、Cursor、GitHub Copilot；创意工具 Midjourney、Suno。2026 年的主线有三条。一是对话助手进入十亿用户量级：ChatGPT 每周约 9 亿活跃用户（2026-02），Gemini App 每月 10 亿用户（2026-08）。二是助手从聊天转向 Agent：Claude 的 Cowork、Gemini Spark、Kimi 的 OK Computer 与 Agent Swarm、Perplexity Computer 都让模型替用户执行多步任务。三是编程 Agent 市场整合：Cognition 收购 Windsurf 后把它并入 Devin，SpaceX 收购 Cursor，GitHub Copilot 改为按 AI 积分计费并接入多家模型。检索日期 2026-11-05。

## 一、对话助手

### ChatGPT（OpenAI）

- 2022-11-30 上线，最初基于 GPT-3.5（本库 `gpt` 页已据 OpenAI 官方资料记录）。
- 2025-08-07 GPT-5 在 ChatGPT 与 API 同时上线，以统一系统形式自动路由快速与推理模型（二手报道，beginnersinai / scriptbyai 时间线汇总）。
- 2025-10-21 发布 AI 浏览器 ChatGPT Atlas，先上 macOS（二手报道，datanorth 等）。2026-07 宣布随 GPT-5.6 关停 Atlas，2026-08-09 停止服务，功能并入新的桌面应用（二手报道，Android Authority、TechRound）。
- 2026-01-16 OpenAI 宣布将在 ChatGPT 测试广告；同日每月 8 美元的 ChatGPT Go 套餐全球上线。2026-02-09 起在美国对已登录的成年 Free / Go 用户测试广告；OpenAI 承诺广告不影响回答、临时对话和未登录状态不显示广告，Plus、Pro、Business、Enterprise 不含广告（二手报道，Gigazine、SiliconANGLE）。
- 用户规模：2025-02 每周 4 亿活跃用户；2026-02 约 9 亿周活、约 5000 万付费订阅（二手报道，援引 OpenAI 的 Nick Turley；另有 CNBC / Reuters 报道内部信息称超过 8 亿）。Sensor Tower 估计 ChatGPT App 月活在 2026-05 或 06 达到 10 亿（二手报道，日期说法不一）。
- 2026-05-05 GPT-5.5 Instant 成为默认模型（二手报道）；GPT-5.6（2026-07）、GPT-6 Astra（2026-09）的发布见本库 `gpt` 页。
- Anthropic 2026-10-22 新闻稿称 ChatGPT 已集成 Agent Skills 标准（一手，见原文摘录）。

- 2026 年 Anthropic Product 分类新闻中与 Claude 应用相关的：04-17 Claude Design（Anthropic Labs 产品，用 Claude Opus 4.7 生成设计、原型、幻灯片，研究预览，Pro / Max / Team / Enterprise 可用）；04-28 Claude for Creative Work；05-13 Claude for Small Business；06-23 Claude Tag（在 Slack 中 @Claude 委派任务，Team / Enterprise beta）；06-30 Claude Science（面向科研人员的工作台应用）；07-09 使用情况回顾功能；07-14 Claude for Teachers（美国 K-12 教师免费使用高级功能）（一手）。
- 2026-05-06 与 SpaceX 签约使用 Colossus 1 数据中心全部算力（超过 300 MW、22 万块以上 NVIDIA GPU），称将直接改善 Pro、Max 订阅用户的容量；同日把 Claude Code 五小时限额翻倍（一手）。
- 套餐（2026-11-05 定价页，一手）：Free（0 美元，网页 / 桌面 / 移动端聊天、联网搜索、创建文件和运行代码、跨对话记忆、连接应用、Artifacts、Claude Design / Slides / Docs）；Pro（月付 20 美元，年付折合 17 美元；含 Claude Code、Claude Science、Projects、Claude in Chrome 与 Microsoft 365、可交接与定时的任务、Claude Dashboards beta；Fable 需用量积分）；Max（100 美元，Pro 的 5 倍用量，Fable 可用到每周额度的一半，含 100 美元 API 积分）；Ultra（200 美元，无五小时限制，Pro 的 10 倍周用量，200 美元 API 积分）。
