# AI 应用产品调研（2026-11）

一句话：补全 L5 应用层，按四组整理十个面向终端用户的 AI 产品，并核实三个已有的编程类应用页。四组是：对话助手 ChatGPT、Claude 应用（claude.ai）、Gemini App、豆包 App、Kimi App；AI 搜索 Perplexity；编程 Agent Devin、Windsurf（2026-06 改名 Devin Desktop），以及已有的 Claude Code、Cursor、GitHub Copilot；创意工具 Midjourney、Suno。2026 年的主线有三条。一是对话助手进入十亿用户量级：ChatGPT 每周约 9 亿活跃用户（2026-02），Gemini App 月活 10 亿（2026-08）。二是助手从聊天转向 Agent：Claude Cowork（2026-09 与聊天合并为一个 Claude）、Gemini Spark、Kimi 的 OK Computer 与 Agent Swarm、Perplexity Computer、ChatGPT Work 都让模型替用户执行多步任务。三是编程 Agent 市场整合：Cognition 收购 Windsurf 并改名 Devin Desktop，SpaceX 收购 Cursor，GitHub Copilot 用 Agent HQ 接入第三方 Agent；同时美国的编程产品大量以中国开放权重模型为基座（Cursor Composer 2 基于 Kimi K2.5，Cognition SWE-1.7 基于 Kimi K2.7）。检索日期 2026-11-05。

- 2022-11-30 上线；两个月月活达 1 亿（Wikipedia）。
- 2025-08-07 GPT-5 在 ChatGPT 与 API 同时上线（本库 `gpt` 页已据 OpenAI 官方资料记录）。

- 2026-01-07 推出 ChatGPT Health，健康相关对话与其他对话分开（Wikipedia）。
- 广告：2026-01-17 宣布在美国对已登录成年 Free 用户测试广告（Wikipedia；二手报道多记为美国时间 01-16，同时推出每月 8 美元的 ChatGPT Go）；2026-03 起用户开始看到广告；2026-08 广告收入达 10 亿美元（Wikipedia）。OpenAI 承诺广告不影响回答，Plus、Pro、Business、Enterprise 不含广告（二手报道）。
- 2026-02 每周 9 亿活跃用户（Wikipedia）；同期约 5000 万付费订阅（二手报道）。2026-08 StatCounter 估计占 AI 聊天机器人市场约 79%；2026-09 为全球第五大访问量网站（Wikipedia）。
- 2026-05-05 GPT-5.5 Instant 成为默认模型（二手报道）；GPT-5.6（2026-07）、GPT-6 Astra（2026-09）见本库 `gpt` 页。
- 2026-07 推出 ChatGPT Work（可基于已连接的应用和文件生成演示文稿、表格等文档的 Agent）；同月 ChatGPT 中的 apps 改名 plugins（Wikipedia）。
- 2026 年面临多起指控 ChatGPT 导致自杀、精神危机的诉讼（Wikipedia）。
- Anthropic 2026-10-22 称 ChatGPT 已集成 Agent Skills（一手）。

### Claude 应用（Anthropic）

- 2023-07-11 随 Claude 2 推出公开 beta 网站 claude.ai，先在美国、英国开放，单次提示可输入 10 万 token（一手）。
- Cowork（全部一手，Claude release notes）：2026-01-12 研究预览，仅 macOS 桌面应用、Max 套餐，把 Claude Code 的 Agent 能力带到编程之外的知识工作，在本机隔离虚拟机中运行，可直接访问本地文件和 MCP；01-16 扩展到 Pro；03-23 Cowork 与 Claude Code 加入 computer use 研究预览，并改进 Dispatch（从手机向电脑上的 Cowork 派任务）；04-09 在 macOS / Windows 桌面应用正式可用；07-07 扩展到网页和移动端，会话在云端运行（beta），先给 Max；09-16 Cowork 与聊天合并为一个 Claude，向 Pro、Max、Ultra 推送。2026-02 面向企业扩大发布并加入插件与连接器，2026-08 进入 Chrome 侧边栏（Wikipedia）。
- 2026 年 Anthropic Product 分类新闻中与 Claude 应用相关的（一手）：04-17 Claude Design（Anthropic Labs，Claude Opus 4.7 驱动，研究预览）；04-28 Claude for Creative Work；05-13 Claude for Small Business；06-23 Claude Tag（Slack 中的团队 Agent，Team / Enterprise beta）；06-30 Claude Science；07-09 使用情况回顾功能；07-14 Claude for Teachers。

- 套餐（2026-11-05 定价页，一手）：Free（0 美元）；Pro（月付 20 美元，年付折合 17 美元；含 Claude Code、Claude Science、Projects、Claude in Chrome 与 Microsoft 365；Fable 需用量积分）；Max（100 美元，Pro 的 5 倍用量，含 100 美元 API 积分）；Ultra（200 美元，无五小时限制，Pro 的 10 倍周用量，含 200 美元 API 积分）。

### Gemini App（Google）

- 2023-02-06 Google 宣布基于 LaMDA 的 Bard；2023-03-21 在美国、英国开放早期访问；2023-05 改用 PaLM 2 并扩展到 180 个国家（Wikipedia）。

- 月活（一手，Google / Alphabet）：Google I/O 2025 超过 4 亿；2025 Q3 约 6.5 亿（搜索摘要转述 Q3 2025 讲话）；2026-02-04（2025 Q4 财报）超过 7.5 亿；2026-07-22（2026 Q2 财报）9.5 亿，日活一年内增至三倍；2026-08-11 超过 10 亿，称是 Google 历史上增长最快的产品；2026-10-28（2026 Q3 财报）称「十亿用户」。2026-05 I/O 时的 9 亿为二手报道。
- 2026-08-11 Google 公布的使用数据（一手）：63% 的用户直接用语音与 Gemini 对话；每天生成超过 1.5 亿张图片；Android 上可在 40 多个热门应用中自动执行操作；iOS 活跃用户超过 1 亿。
- 2026-05 发布个人 Agent Gemini Spark（Wikipedia）；2026-07-22 财报讲话称 Spark 已在美国及国际上线（一手，搜索摘要）。同届 I/O（2026-05-19）发布视频多模态模型 Gemini Omni 和 Gemini 3.5（Wikipedia）。Spark 在 Google Cloud 专用虚拟机上运行、Daily Brief、Neural Expressive 改版、macOS 应用等细节为二手报道。
