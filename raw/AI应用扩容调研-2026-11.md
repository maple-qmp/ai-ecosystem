# AI 应用扩容调研（2026-11）

一句话：在 `AI应用产品调研-2026-11` 的基础上扩充 L5 应用层，补五组产品：办公与企业（Microsoft 365 Copilot、Notion AI、Salesforce Agentforce）、AI 浏览器与 Computer Use（ChatGPT Atlas、Perplexity Comet、Gemini in Chrome、Dia、Opera Neon 及其底层能力 computer use）、垂直行业（法律 Harvey、医疗 OpenEvidence 与 Abridge、金融 Rogo）、视频与创意（Runway）、陪伴类（Character.AI）。2026 年的主线有三条：一是办公套件把助手升级为 Agent，并走向“多模型”——Microsoft 365 Copilot 同时接入 OpenAI 与 Anthropic 模型，Copilot Cowork 直接采用 Claude Cowork 的技术，Notion 让用户自选 GPT、Claude、Kimi 等模型；二是 AI 浏览器从独立产品退回到既有入口：ChatGPT Atlas 上线不到一年即关停并入 ChatGPT 桌面应用，Comet 改为免费，Chrome 自带 Gemini 自动浏览；三是垂直行业应用估值快速抬升并开始自研模型（Harvey 155 亿美元估值、发布开放权重模型 Tenet；OpenEvidence 推出自有模型家族），而陪伴类头部 Character.AI 在诉讼与未成年人禁令后于 2026-10 申请破产保护。检索日期 2026-11-07。

## 一、办公与企业

### Microsoft 365 Copilot（Microsoft）

- 内嵌在 Word、Excel、PowerPoint、Outlook、Teams 中的助手，另有 Copilot Chat；单独购买时为每用户每月 30 美元的附加许可（二手）。
- 2026-02 起 Word、Excel、PowerPoint 网页版逐步推出 Agent Mode（二手）。
- 2026-03-09 Microsoft 发布「Wave 3」（一手）：Copilot Cowork 与 Anthropic 合作，把 Claude Cowork 的底层技术带进 Microsoft 365 Copilot，执行长时间多步任务，先经 Frontier 计划提供；Claude 进入主线 Copilot Chat（Frontier 计划），与最新 OpenAI 模型并列；Word、Excel、PowerPoint、Outlook、Copilot Chat 当月推出新一代 Agent 体验；Agent 365（管理和保护 AI Agent 的控制平面）与 Microsoft 365 E7「Frontier Suite」均于 2026-05-01 正式可用。E7 打包 E5、Copilot、Agent 365 以及 Entra Suite 与高级安全组件（一手）。

### Notion AI（Notion Labs）

## 二、AI 浏览器与 Computer Use

### Computer use（能力）

- 定义：模型通过截图感知屏幕，再输出鼠标移动、点击、键盘输入等动作，像人一样操作图形界面。Anthropic 2024-10-22 随升级版 Claude 3.5 Sonnet 推出 computer use 公测，OSWorld 仅截图类别 14.9%，放宽步数 22.0%（一手）。
- OpenAI 2025-01 推出 Operator（基于 Computer-Using Agent 模型），OSWorld 50 步 32.6%（二手，发布时自报）。后来并入 ChatGPT 的 agent 模式（训练知识，待核实）。
- 2026 年 OSWorld-Verified 头部成绩约 80%（2026-04 H Company Holo3 80.4%，开放权重 Kimi K2.6 73.1%），另有 OSWorld 2.0（108 个长程桌面工作流）排行榜（二手）。
- 产品形态：浏览器 Agent（Atlas agent 模式、Comet Assistant、Chrome auto browse）、桌面 Agent（Claude Cowork 2026-03 加入 computer use 研究预览；Notion Agent 2026-10 自带计算机和浏览器）、API 工具（Claude computer use 工具、GPT 系列 computer use）。

### AI 浏览器

- **ChatGPT Atlas**（OpenAI）：2025-10-21 上线 macOS；2026-03 宣布与 ChatGPT 桌面应用、Codex 合并；2026-08-09 关停（沿用前一份调研，Wikipedia）。
- **Comet**（Perplexity）：2025-07 推出，先限 Max 订阅；2025-10 全球免费（二手）；2026-03 Amazon 诉讼禁令后被撤销（见 Perplexity 页）。
- **Gemini in Chrome**（Google）：2026-01-28 推出 Gemini 3 驱动的 auto browse，可替用户滚动、点击、输入，先向美国 AI Pro / Ultra 订阅用户开放，有每日次数限制，支持 Universal Commerce Protocol（二手）。
- **Dia**（The Browser Company，2025 年被 Atlassian 收购）：Arc 的继任者，仅 macOS，Pro 档 20 美元 / 月（二手；收购事项为训练知识，待核实）。
- **Opera Neon**（Opera）：Agent 层收费，19.90 美元 / 月（二手）。
- 格局：Chrome 仍占全球约三分之二使用量（二手）。
